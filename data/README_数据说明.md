# 外部可复现测试数据

本目录中的数据由 `scripts/generate_dcu_285_data.py` 生成，生成公式和类型固定，未使用随机数。重新生成同样的尺寸和深度应得到相同内容。

这些文件对应送测协议中的 `package_file:<文件名>` 数据源。每个函数的
`data_source` 必须明确使用以下一种口径：

- `internal_deterministic`：按清单规定的固定公式、数据类型、维度、尺寸和
  参数，在 benchmark 内部生成输入；
- `package_file:<文件名>`：读取本目录中指定的 MHA/CSV 文件。

使用文件时，结果中必须保留文件名、尺寸、像素类型和 SHA-256。两种来源
分别汇总，不能把一种输入源的结果代替另一种输入源的结果。
